# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Contact the
repository maintainers privately through GitHub so the issue can be assessed
before disclosure.

Include the affected version, reproduction steps, impact, and a suggested fix
when available. Do not include credentials or private repository contents.

Blackbox is designed for local storage. Review `.git/blackbox/` permissions
and backups as you would any other local developer data.
